Esta página reúne los elementos aprobados para escribir posts. Cada post es un archivo MDX en `content/posts/<id>/<idioma>.mdx` con su `export const meta`, registrado en `content/posts/registry.ts`. Publicar un post es hacer merge a `main`.

## Texto y estructura

Los párrafos, las **negritas**, las *cursivas* y los [enlaces](/es/blog) funcionan como en Markdown. Usa `##` para las secciones y `###` para las subsecciones: cada encabezado recibe un ancla, y si el post tiene tres o más, aparece el índice al inicio.

- Listas con viñetas.
- Listas numeradas.
- Citas con `>`.

> Una cita se ve así: con la barra a la izquierda, como los separadores de 2023.

### Tiempo de lectura

Se calcula solo, a 200 palabras por minuto, sin contar los bloques de código.

## Código

Los bloques de código se resaltan en el servidor con sugar-high, sin JavaScript en el navegador, y llevan un botón para copiarlos:

```ts
export function readingMinutes(words: number): number {
  return Math.max(1, Math.ceil(words / 200))
}
```

```bash
npm run verify
```
